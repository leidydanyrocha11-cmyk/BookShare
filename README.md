# 🚀 Projeto: BookShare – Sistema de Troca e Doação de Livros

## 👥 Integrantes

- Danielly Rocha Silva

## 📌 Visão do Produto

O BookShare é um sistema desenvolvido para facilitar a troca e a doação de livros entre usuários. A plataforma permite que pessoas cadastrem livros que desejam doar ou trocar, pesquisem livros disponíveis e entrem em contato com outros usuários de forma simples e organizada.

O objetivo é incentivar a leitura, promover o reaproveitamento de livros e facilitar o acesso à informação.

## 📋 Requisitos do Sistema

### Requisitos Funcionais (RF)

- RF01: O usuário deve conseguir criar uma conta.
- RF02: O usuário deve realizar login no sistema.
- RF03: O usuário deve cadastrar livros para doação ou troca.
- RF04: O usuário deve visualizar todos os livros disponíveis.
- RF05: O usuário deve pesquisar livros pelo título ou autor.
- RF06: O usuário deve solicitar uma troca ou doação.
- RF07: O usuário deve editar ou excluir seus próprios anúncios.

### Requisitos Não Funcionais (RNF)

- RNF01: A autenticação dos usuários deverá utilizar JWT.
- RNF02: O frontend deverá ser desenvolvido como uma Single Page Application (SPA).
- RNF03: O sistema deverá possuir interface responsiva.
- RNF04: O tempo de resposta da API deverá ser inferior a 200 ms.
- RNF05: Os dados deverão ser armazenados em banco de dados.

## 🎯 Objetivo

Desenvolver uma aplicação web que permita aos usuários compartilhar livros de maneira simples, rápida e segura, incentivando a leitura e reduzindo o desperdício de materiais.
